# Shriya Jedhe — Personal Portfolio

Responsive portfolio made with plain HTML, CSS and JavaScript. No framework, npm install, or build command is needed.

## Files
- `index.html` — page content, education, experience and projects
- `style.css` — responsive layout, gradient theme and animations
- `script.js` — animated headline, mobile menu, project filters and contact actions
- `assets/` — folders for resumes, certificates, publication/copyright PDFs and the Crop Protection demo video

## Run on Windows
1. Extract the ZIP to a folder such as `C:\Users\shriy\Documents\shriya_portfolio`.
2. Open VS Code → **File → Open Folder** → select the extracted folder.
3. Install the **Live Server** extension by Ritwick Dey (if not already installed).
4. Right-click `index.html` → **Open with Live Server**. Or double-click `index.html` to open it directly in a browser.
5. Edit a file, save it, and refresh the browser if needed.

## Personalize before publishing
1. Open `script.js` and replace `YOUR_EMAIL@example.com`, `YOUR_GITHUB_USERNAME`, and `YOUR_LINKEDIN_USERNAME` with your real details.
2. Check your B.Tech dates and experience descriptions against your official records.
3. Add your real repository/demo URLs to project cards. Delete any project you do not want to show yet.
4. Add your two resume PDFs under `assets/resumes/` using the exact filenames `Shriya-Jedhe-AI-ML-Resume.pdf` and `Shriya-Jedhe-Software-Developer-Resume.pdf`. The Resume/CV section already contains View and Download links.
5. Add your official paper PDF to `assets/publications/Crop-Protection-Research-Paper.pdf` and your copyright certificate to `assets/copyright/Copyright-Certificate.pdf`.
6. Add certificate PDFs under `assets/certificates/` using the filenames shown in the Certificates section, or update those links in `index.html`. You can also add image files and update the section to display them as thumbnails.
7. Add your Crop Protection output video as `assets/videos/crop-protection-demo.mp4`, or replace that project link with a YouTube/Google Drive URL.
8. Replace the Weather Monitoring Tinkercad placeholder link in `index.html` with your real simulation share URL. The Smart Building simulation link is already included.
9. For the Email for Blind and Online Stationery Store, replace the “Add live demo URL” link with the actual deployed URL when available. Do not use a local `file:///` URL for a public portfolio.

The assets are not included until you add your actual files. No publication citation, copyright registration number, certificate, or project demo URL has been invented. Don't publish personal contact details unless you are comfortable making them public.

## Deploy free on Vercel
1. Sign in to GitHub and create a repository named `shriya-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and the complete `assets/` folder (including the PDFs/video you want public) using **Add file → Upload files**.
3. Sign in to Vercel with GitHub.
4. Choose **Add New → Project**, then import `shriya-portfolio`.
5. For this plain static site, choose **Other** if asked for a framework preset. Leave build command and output directory blank unless Vercel prompts otherwise, then deploy.
6. Open the `vercel.app` URL Vercel gives you.
7. Later, push changes to GitHub; Vercel can redeploy the connected project automatically.

## Notes
- The contact email button opens the visitor's email app; it is not a hosted contact form.
- Anything in a public GitHub repository or deployed website can be viewed publicly.
- Project descriptions are starter copy based on the project details available. Make sure each description accurately reflects what you implemented before publishing.
