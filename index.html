How to upload or replace a resume

  1. Save your final resume as a PDF using one of the exact filenames shown on the cards.
  2. Copy it into the matching folder under assets/resumes/. If you use a different filename, update the two links for that resume in index.html.
  3. For GitHub/Vercel, upload the changed PDF and commit/push the update. Vercel redeploys the site automatically when connected to GitHub.
  4. Open the deployed site and test both View PDF and Download buttons.

This is a static portfolio: file replacement is done by the site owner in the project folder, not by public visitors uploading files through the website.
